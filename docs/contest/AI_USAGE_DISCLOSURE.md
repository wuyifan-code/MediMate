# 人工智能工具使用说明

本项目如实披露生成式人工智能在开发和内容整理中的使用情况。AI 工具不替代团队对需求、架构、算法、数据和最终作品的判断。

## 使用环节

- MiniMax：在服务记录已经存在的前提下，生成家属可读的陪诊纪要草稿；团队负责提示词、输入边界、失败处理、人工确认和最终发布。
- MiniMax：将已计算的匹配结果整理为自然语言推荐理由；分数、硬约束和排序由系统代码计算。
- 通用代码辅助工具：用于排查错误、生成局部代码草稿和整理文档；团队负责设计、修改、联调和测试。

## 未交给 AI 决定的事项

AI 不决定订单状态、GPS 是否验证通过、信任分、节点是否完成、医疗诊断、急救判断和用户权限。

## 数据与版权

比赛演示使用合成的人物、医院、服务和医疗信息，不向模型发送真实患者隐私。第三方图片、字体、模型和代码使用情况应在最终提交材料中逐项核对并补充来源。
