# 4 分钟演示脚本

## 0:00-0:25 问题

“当子女无法陪在身边时，一次由陌生人完成的陪诊服务，家属最担心的是人选是否合适、过程进行到哪一步、结束后发生了什么。”

## 0:25-1:10 需求与匹配

用合成场景“李阿姨，68 岁，骨科复诊，行动略有不便”填写服务需求。展示候选人的专长、距离、档期、价格和信任指标，展开第一名的推荐理由与限制。

## 1:10-2:10 服务路径

进入订单，展示到院、取号、候诊、面诊和离院节点。强调“记录上传”和“节点完成”是两个状态。

## 2:10-2:50 家属进度

切换到家属视角，展示当前步骤、更新时间、异常提示和下一步安排。

## 2:50-3:35 纪要与完整性

根据已经存在的服务记录生成纪要草稿，展示来源记录。修改一条记录后重新校验，演示完整性指纹失败。

## 3:35-4:00 边界与收束

说明 AI 负责表达，代码负责事实、权限、节点和状态；比赛数据为合成数据；系统提供陪诊协作支持，不替代医生诊断。
